# Team workspace / 团队工作空间

## English

1. Register or sign in. New accounts create an organization or follow a private invitation link. Existing migrated accounts receive a personal organization containing their old projects. Passwords and unexpired sessions are preserved.
2. Use the organization switcher to choose the company you are working with. Your role can differ in each organization. The selected organization scopes projects, members and audit.
3. Owners/admins open Members to invite a teammate by exact email and role. Share the generated link privately. It expires in 48 hours and can be accepted only once, by the matching logged-in account. Revoke unused links when needed. Only owners invite/manage administrators.
4. Create projects and open a project card to edit title, description or stage. Add tasks, choose an active member as assignee, set a due date and comment. Save changes explicitly. Project deletion removes its tasks and comments after confirmation.
5. Viewers can read but cannot modify. Members collaborate. Administrators manage ordinary members/viewers and settings. Owners additionally manage administrators and transfer ownership to another active member. Ownership transfer makes the previous owner an administrator. The only owner cannot be removed/demoted using member controls.
6. Removed members immediately lose organization access, including from their existing session. Their assigned tasks become unassigned; historical comments/audit remain attributable. A role change does not affect the person's other organizations.
7. Owners/admins inspect the latest 100 Audit log events. Records include action, actor, object, date, request ID and applicable changes. The interface has no audit edit/delete operation.
8. Select Chinese or English in the header; preference survives reload/navigation. Refresh fetches current organization data and membership. Use Help for the same operating guidance.

## 中文

1. 注册或登录后创建组织，或通过私密邀请链接加入。迁移的老账号会获得一个包含原项目的个人组织，密码与未过期会话保留。
2. 使用组织切换器选择当前企业。你在不同企业可拥有不同角色；项目、成员和审计均以当前企业为范围。
3. 所有者或管理员在成员页填写同事邮箱与角色，创建并私下分享邀请链接。链接 48 小时后过期，只能由匹配邮箱的登录账号接受一次。未接受的链接可以撤销；只有所有者可以邀请和管理管理员。
4. 创建项目后点击卡片，编辑名称、说明和阶段。添加任务、分配组织内成员、设定截止日期并发表评论，修改后明确保存。删除项目会在确认后同时删除其任务和评论。
5. 只读成员只能查看，普通成员可以协作，管理员管理普通/只读成员及设置，所有者还可管理管理员并转移所有权。转移后原所有者成为管理员。唯一所有者不可通过普通成员操作被移除或降权。
6. 移除成员立即取消其组织访问权，即使其登录会话仍有效；任务负责人会清空，历史评论和审计保留。角色调整不影响其在其他组织的权限。
7. 所有者和管理员查看最近 100 条审计，包含动作、操作者、对象、日期、请求编号及适用的修改信息。界面不提供修改或删除审计操作。
8. 顶部切换中英文，偏好在刷新和导航后保留。刷新获取最新数据与成员权限；帮助页提供相同操作指引。
